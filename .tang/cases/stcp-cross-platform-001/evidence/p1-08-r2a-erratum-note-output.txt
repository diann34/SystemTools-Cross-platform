1) 扫描器大小写语义（R-2 实际正则，-match 为 PowerShell 大小写不敏感运算符）：
  '#if PLATFORMS_WINDOWS' -match '^#\s*if\s+PLATFORMS_WINDOWS\s*$'  => True（全大写写法亦被识别为形态 a 正向 guard）
  '#if Platforms_Windows' -match '^#\s*if\s+PLATFORMS_WINDOWS\s*$'  => True（编译生效驼峰写法被识别）
  '#elif Platforms_Windows' -match '^#\s*elif\s+PLATFORMS_WINDOWS\s*$' => True
  '#if !Platforms_Windows' -match '^#\s*if\s+PLATFORMS_WINDOWS\s*$' => False（取反形态不识别为正向 guard，从严不变）
  结论：扫描器对两种大小写写法均按正向 guard 识别（分流语义一致，无需改扫描器）；
        全大写写法因 DefineConstants 未定义该符号，在 windows TFM 亦编译为排除 → 属死代码形态。
